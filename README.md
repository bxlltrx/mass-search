# Массовый поиск подстрок с использованием CUDA

## Описание

В данной лабораторной работе реализован алгоритм массового поиска подстрок в массиве байтов с использованием технологии CUDA.

Программа выполняет сравнение производительности:

- последовательного поиска на CPU;
- параллельного поиска на GPU.

Для тестирования случайным образом генерируется массив байтов, после чего из него формируется набор шаблонов различной длины.

---

# Используемые технологии

- Python
- NumPy
- Numba CUDA

---

# Параметры эксперимента

| Параметр | Значение |
|---|---|
| Размер массива данных | 50000 |
| Количество шаблонов | 100 |
| Размер шаблонов | 3–15 байт |
| Используемый GPU | Tesla T4 |

---

# Принцип работы

## CPU-версия

Последовательный алгоритм перебирает:

1. каждую подстроку;
2. каждую возможную позицию;
3. посимвольно сравнивает данные.

---

## GPU-версия

В CUDA используется параллельная обработка.

Каждый поток GPU отвечает за одну проверку:

```text
(шаблон, позиция)
```

Поток сравнивает байты шаблона с участком исходного массива.  
Если все элементы совпадают — фиксируется найденное вхождение.
